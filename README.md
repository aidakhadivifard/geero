# Dawnhalo

A daily affirmation & oracle-card web app — a quiet moment of perspective each day.
This is the production rebuild of the Lovable HTML prototype: the exact design
(Cormorant Garamond + Outfit, canvas/ink/gold/clay/sage palette, the four "wash"
gradients, pricing, paywall, crisis copy) with real functionality wired in.

## Stack

- **Frontend:** React + Vite + Tailwind CSS (config mirrors the prototype's tokens)
- **Backend:** Node + Express — proxies the Anthropic API so the key never reaches the browser
- **AI:** Anthropic Claude for card generation
- **Storage:** local-only (`localStorage`) — no auth, no cloud sync

## Run it

```bash
npm install
cp .env.example .env          # add ANTHROPIC_API_KEY (or set DAWNHALO_ALLOW_FALLBACK=1)
npm run dev                   # web :5173, API :8787 (proxied)
```

Open **http://localhost:5173**. Recipient share view: **/spark**.
Production single server: `npm run build && npm start` → http://localhost:8787.

### The model

The brief asked for `claude-sonnet-4-20250514`, but that model is **deprecated and
retiring 2026-06-15**. The app uses **`claude-sonnet-4-6`** — the current Sonnet and
Anthropic's drop-in replacement (same family/API). It's one constant, `MODEL`, in
`server/cardGenerator.js`.

### The key

Card text is generated by Claude via the server. Without a key, `/api/card` returns a
clear 503; set `DAWNHALO_ALLOW_FALLBACK=1` to serve curated offline demo cards (these
mirror the prototype's copy so the demo looks identical).

## What's wired in

- **Real card generation** — daily (cached once/day), question ("ask"), and feeling
  ("feel") cards. System prompt encodes the brand voice, **validate-before-reframe**,
  **no appearance focus**, and the **loneliness rule** (affirm worth directly, never
  invent a fictional admirer). One follow-up per card.
- **Crisis detection** — a deterministic keyword gate (`shared/crisis.js`, shared by
  client + server) runs **before any model call**; on a hit it shows the support panel
  (988 / Samaritans 116 123) and never calls Claude.
- **Send a Spark** — encodes the card in a URL, opens the native share sheet (Web Share
  API, clipboard fallback); the `/spark` page shows the card + "Draw your own card".
- **Saved** — grid of collected cards; tap to reopen read-only (Spark still available).
- **Calendar + streak** — monthly view, tinted days hold cards, dots mark visits; streak
  in the header.
- **Voice input** — Web Speech API transcription into the composer, graceful fallback.
- **Paywall + plans** — 3 free draws, then the paywall; pricing preserved
  ($4.99/mo yearly, $9.99/mo monthly).

## Tests (test-driven, build order per the PRD)

`npm test` → **79 passing** (Vitest + Testing Library):

1. **Crisis detection** — true positives + true negatives (incl. loneliness/everyday stress)
2. **Intent classification** — question vs feeling
3. **Card generation** — structured output, crisis short-circuit, fallback, classify fallback (Anthropic SDK mocked)
4. **Store** — streak/date logic, free-draw counter, save/retrieve, history, daily cache, Spark codec
5. **Components** — the one-follow-up constraint, read-only mode
6. **End-to-end journey** — open → daily → ask → result → collect → appears in Saved

## Layout

```
shared/crisis.js        crisis detection (one source for client + server)
server/
  cardGenerator.js      Claude call, system prompt, structured schema, fallback
  classify.js           question/feeling intent fallback
  safety.js             re-exports shared crisis logic
  index.js              Express: /api/card, /api/health, prod static
src/
  components/           Header, BottomNav, CardView, CardResult, Composer,
                        CrisisPanel, Paywall, Plans, Today/Saved/Calendar/Settings, CardSheet
  store.js              local persistence, streak, wash selection, Spark codec
  api.js, SparkPage.jsx, App.jsx, main.jsx, index.css
```

## Out of scope (PRD §6)
